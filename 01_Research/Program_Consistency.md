# 社区中心的空间功能有多一致？——任务书查漏的依据

日期：2026-10-22。起因：用户问"不同社区中心的空间功能是否一致？如果一份任务书没给全，能不能有 skill 检查漏掉的功能并补上"。做法：把已读平面的房间清单（图例）逐个对照，数每种功能在几个案例里出现，再和温哥华《社区中心战略》（2022）目标 9 / 10 和 Marpole 2021 任务书的房间表对照。做成 skill `.claude/skills/community-centre-program-check/`。

**样本：** 读到图例或房间标注的 14 个案例——Marpole 2011（Patkau）、Clayton、Churchill Meadows、Sixteen Mile、Western North York、East Bayfront、Redmond、Gleneagles、Kenilworth、Toyotomi、Sport England 2014 范式、Kingston、Commonwealth、Eastside El Paso。"出现"指图上标了这个房间；没标不等于没有（小房间常不标），所以数字是下限。证据强度 B（图例读取，没有逐个核对面积表）。

## 1. 一致性：核心功能高度一致，差别在"锚"和"社区专属房间"

| 功能 | 出现 / 14 | 说明 |
|---|---|---|
| 门厅 + 接待 | 14 | 全部；形式从一条街道到一个 living room |
| 体育馆（≥ 1 片场地） | 13 | Toyotomi 是多功能大厅代替 |
| 多功能室 / 活动室（≥ 2 间） | 14 | 名字不同（program room、activity、studio、meeting） |
| 健身中心 | 12 | Toyotomi、East Bayfront（小，没标）无 |
| 更衣室 | 12 | 有体育馆或泳池就有 |
| 公共卫生间 | 14 | |
| 行政 / 员工办公 | 13 | |
| 储藏（标出来的） | 11 | 几乎总是贴着大件 |
| 泳池 | 7 | 是"锚"：有就决定了平面的一半 |
| 大厅 / 表演厅 / 宴会厅（带舞台或餐厅） | 6 | Clayton、Redmond、Toyotomi、Marpole 2011（看台）、Five Acres、Sport England 无 |
| 厨房（商业 / 教学 / 社区） | 7 | 几乎都贴大厅或老人室 |
| 青少年室 | 5 | 温哥华、多伦多案例多有；美国案例叫 teen lounge |
| 老人 / 社区休息室 | 5 | 美国案例叫 senior lounge；温哥华叫 seniors centre |
| 托儿 / 学前 / 儿童室 | 7 | 温哥华项目几乎都有（Marpole、Clayton、Gleneagles、WNYCC） |
| 艺术 / 手工 / 音乐室 | 6 | |
| 咖啡 / 小卖部 | 7 | 温哥华案例几乎都有 |
| 图书馆 | 3 | 合建时才有（Sixteen Mile、Clayton、Hebburn） |
| 跑道 | 5 | 有二层健身时常带 |
| 壁球 / 攀岩 / 滑板等专项 | 4 | 地方性 |
| 球场小屋 / 室外卫生间 | 3 | 公园场地 |
| 机房 / 电气 / 清洁 / 垃圾（标出来的） | 9 | 概念图常省略，施工图必有 |

**结论：** 前 8 行（门厅、体育馆、多功能、健身、更衣、卫生间、行政、储藏）是跨城市、跨规模一致的"骨架"，和温哥华战略目标 9 的清单基本重合。差别有两层：① **锚**（泳池 / 冰场 / 图书馆 / 剧场）——由片区供给决定，战略目标 10 就是这一层；② **社区专属房间**（青少年、老人、托儿、厨房、艺术）——温哥华项目几乎都有，是本地任务书的特点，不是通用项。

## 2. 任务书最容易漏的是支持空间

对照 Marpole 2021 的房间表（它是一份完整的专业任务书）和案例图例，概念阶段的任务书 / 学生的功能清单常漏掉：

| 常漏的项 | Marpole 的数字（可作补上时的假设） | 为什么漏 |
|---|---|---|
| 每个大件的储藏 | 体育馆储藏 = 体育馆面积 8%；多功能厅 2 × 125 ft²；每间活动室 30–100 ft² | 当成"附属"，没单列 |
| 机房、空调、电气、泳池机房、化学品 | 设备与后勤合计约 5,756 ft² ≈ 净面积 16%（含托儿机房） | 概念图不画 |
| 清洁间（每层、每组团） | 门厅 40、厨房 35、后勤 2 × 40 ft² | 太小 |
| 员工卫生间、员工休息 | 50 + 250 ft² | 和公共卫生间混了 |
| 急救室、救生员 / 员工办公 | 120 + 130 ft² | 只有泳池 / 健身项目想得到 |
| 通用 / 家庭卫生间、成人护理台 | 2 × 50 + 145 ft² | 新近的无障碍要求 |
| 门斗、排队区、婴儿车停放、饮水 | 门厅里 390 + 75 + 75 + 15 ft² | 算在"门厅"一个数里 |
| 青少年室内的员工办公（"没有死角"） | 100 ft² 在房间内 | 运营要求，设计者不知道 |
| 垃圾分类、IT、通信入口、发电机、电梯机房 | 160 + 150 + 100 + 205 + 160 ft² | 施工阶段才出现 |
| 球场小屋（公园场地） | 2 × 350 + 480 + 50 ft² | 场地专属 |
| 室外：直通室外的场地（舞台、游戏场、篮球场）、自行车棚 | 见 Marpole 室外空间 8 | 不算建筑面积 |

## 3. 能不能自动补上
能做成 skill，但分两步，不能一键：
1. **查漏**（自动）：把任务书的清单按第 1 节的表打勾，按四级报告——A 必有（温哥华战略目标 9）、B 案例里几乎都有、C 常见、D 片区级 / 场地专属（目标 10、泳池、球场小屋）。再按第 2 节查支持空间。
2. **补上**（给建议，用户决定）：每一项补上的功能带面积（先用 Marpole 的数，标"借用 Marpole 2021"）、最低阶段（按 `STAGE_RULES.md` R1–R8 推）、放在哪（按 `community-centre-layout` 的规则）。补上的项在工具里标"任务书未列，按案例补（假设）"，不混进"已核实"。

不能自动的：锚（要不要泳池、冰场）和社区专属房间（青少年、老人、托儿）取决于片区供给和社区需求，skill 只能提示"温哥华项目通常有、你没列"，不能替用户决定。
