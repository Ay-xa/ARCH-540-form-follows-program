# 排布的评判准则（第 1 稿）

日期：2026-10-17。状态：草稿，依据是用户 2026-10-17 的一系列决定；数值参数一律标“假设”，需要你核对。

## 1. 排布的做法（用户同意）
“大件优先、就近最优”：像在平面上摆家具。
1. 先放最大、限制最多的；必有功能先放，选填功能后放。
2. 每个功能在体块里找一个得分最高的位置。
3. 位置可以跨越南、北、中间三带；**三带只是评判背景，不是容器。**
4. 放不下的功能，提示原因：面积不够 / 没有合适的区域 / 面积被分割。
5. 设计师挪体块或改参数，工具重新摆一次（见第 6 节）。

**放置顺序（我的建议）：** 门厅（固定在入口）→ 体育馆 → 健身与康养 → 其余必有功能按面积从大到小 → 咖啡 → 选填功能（勾选后）。小厨房和卫生间属于服务空间，倾向放在中间带。

## 2. 硬约束（不满足就不能放）
- 房间完整落在体块内，房间之间不重叠。
- 不小于功能的最小单个面积和最小边长。
- **体育馆：** 一个无柱的矩形，短边至少约 21 m（来自搜索摘要里较旧的 Sport England 资料，30.1 × 21.1 m 篮球场加休闲级缓冲区，待核对）。体育馆不能拆分。
- **门厅：** 紧贴入口所在的立面（默认南立面，设计师可以挪动）。

## 3. 软评判（排布好不好），按优先顺序

> **2026-10-18 更新（用户确认）：** 最前面加了“楼层适配”（功能库里“最好首层 / 最好二层”的功能，在对应楼层为 1，否则为 0），排在带适配之前。硬约束加了最小净高和“必须首层”。见 `Assignment_2/Architecture_Massing_Level_Space_Program.md` 阶段 4。
用户同意：**带适配优先于渐变适配**（冬季优先，阳光对久坐的功能最关键）。第一版不设数值权重，只按优先顺序比较；前一项相同时再比下一项。

| 优先 | 评判项 | 怎么算 | 状态 |
|---|---|---|---|
| 1 | 带适配 | 房间面积中，落在它偏好的带里的比例（需要阳光的看南带，不需要直射阳光的看北带，服务空间看中间带）。**偏好南带或北带的房间，要贴着对应的外立面才算完全适配**（见 3（补）） | 用户决定（规则）；比例是计算 |
| 2 | 渐变适配 | 耐受气候强（最低阶段低）的靠外，敏感（最低阶段高）的靠内。靠外靠内用房间中心到外墙的距离衡量，**只量到南、北立面，不量到东、西山墙**（见 3（补））。目标位置与最低阶段的对应关系是我的假设：阶段越高越靠内，线性对应 | 用户确认方向；对应关系为假设 |
| 3 | 形状 | 长宽比在功能允许的范围内；超出就扣分 | 范围为假设 |
| 4 | 简洁 | 面积相同时，房间数量更少、整体更规整的排布更好 | 用户决定（拆分是为了排布更简洁） |

### 3（补）两条补充（用户 2026-10-17 决定）
第一版跑出来后发现：带适配只问“房间有多少在带里”，整个房间在带内就是 100%，贴不贴立面没区别；接着渐变适配要求阶段高的房间越靠里越好，于是南侧的房间漂到南带的内沿，不贴南立面；门厅也因为“离最近外墙的距离”把西山墙算了进去，离西南角空出几米。用户同意补两条：

1. **贴立面才算完全适配。** 偏好南带或北带的房间，贴着对应的外立面（南立面或北立面）时，带适配 = 落在带里的面积比例；没贴着时按它离立面的空隙打折。理由：阳光和漫射光都是从立面进来的，在带里但不靠立面的房间拿不到光。偏好中间带的服务空间没有对应的立面，不打折。
   - 打折的算法（第一版）：带适配 = 带内面积比例 × 立面系数；立面系数 = 1 − 空隙 ÷ 带深度，最低为 0。**线性打折是我的写法，状态：假设**；“贴着才算完全适配”是用户决定。
2. **深度只量到南、北立面。** 渐变适配里“房间中心到外墙的距离”只取到南立面和北立面两者中较近的一个，不算东、西山墙；最大可能深度 = 体块南北进深的一半。理由：三带沿东西方向划分，渐变是从南北立面往里走的深度，山墙不参与这个渐变。

## 4. 面积的拆分（用户 2026-10-17 决定）
- 一个功能的大面积可以拆成多个小房间，目的是让排布更简洁。例：某种教室总面积 2000 m²，可以拆成 4 个 500 m²。
- **做法（用户 2026-10-18 决定，取代原来的“放不下或排布不好再拆”）：**
  1. **有天然标准单间的功能**（例如教室）：功能库直接写“标准单间面积和数量”，总面积 = 数量 × 单间面积，不存在“拆”这个动作。多功能室目前就是 2 间 × 93 m²。
  2. **其他可拆的功能：** 设一个**最大单间面积**，超过就必须拆成最少的几间（间数 = 总面积 ÷ 最大单间面积，向上取整）。例如多功能室最大单间 140 m²（假设），把每间面积覆盖成 200 m²，就拆成 2 间，每间 100 m²。
  3. 不超过最大单间面积的，先按整间放；整间放不下时，仍然试着拆成更小的房间。
  4. 每个拆出来的房间不小于该功能的最小单个面积。
  5. “用打分判断排布好不好再决定拆不拆”放到以后，等看到更多实际排布的例子。
- 功能库每个可拆分的功能需要三项：可否拆分、最小单个面积、最大单个面积。体育馆不可拆分。第一版只有多功能室可拆：最小单间 60 m²、最大单间 140 m²，**都是假设**，待你设定。

## 4（补）房间形状的适配（用户 2026-10-17 要求）
工具要能调整房间的长宽，让它们适配在体块里：面积保持不变，长宽比在功能允许的范围内变化。体育馆的最小短边是硬约束，其他功能的长宽比范围目前没有来源，第一版用假设值，待设定。

## 5. 点击房间时，侧栏显示“为什么放在这里”（用户要求）
1. 名称、类别（核心、支持、过渡；必有或选填）。
2. 面积，以及面积的状态标签（已核实、来源待核对、假设、用户设定）。
3. **位置的原因：**
   - 带适配：偏好哪一带，实际有百分之几落在其中；
   - 渐变位置：它的最低阶段是什么，现在靠外还是靠内；
   - 形状：长宽比、是否满足最小边长；
   - 入口：门厅是否紧贴入口。
4. **触发的规则：** R1 到 R8 中哪些适用，冬季和夏季的最低阶段各是什么。
5. **阶段检查：** 设计师指派的阶段与最低阶段比较，满足、不满足，还是过度调节。
6. **没有满足的地方和建议：** 先给功能调整的建议（用户决定先做这个）。
7. **来源与状态标签：** 借用的、假设的值都要标明。

## 6. 挪动入口或改参数之后要不要重新生成
- 原则：同样的输入得到同样的排布（可重复），所以任何输入变化都可以重新计算。
- 问题：设计师不希望每挪一下，所有房间都乱跳。我的建议是三层：
  1. **小改动（挪入口）：** 只更新受影响的房间（门厅和与它相邻的），其他房间尽量保持原位，只要仍然满足硬约束。
  2. **大改动（改体块大小、改带深度）：** 自动重新生成。
  3. **锁定：** 设计师可以锁定满意的房间，重新生成时把它们当作已有的，只重排其余的。另外保留一个“重新生成”按钮，用来整体重来一次。
- **（2026-10-18 已决定，取代本节建议）** 见 `Assignment_2/Architecture_Massing_Level_Space_Program.md` 第 2.5 节和第 5 节第 7 条：仍满足的保留；不满足的标红给建议，用户接受后才改；锁定的不动；平面里拖过的功能区自动锁定。

## 8. 渐变序列取代“渐变适配”（2026-10-20，用户决定）
**背景：** 回看最初的目标（conditioned space 是从气候防护到环境暴露的渐变；空间的防护程度决定它能承接什么活动；“刚好够”；主动调节最小化），发现排布引擎把阶段只当标签：房间继承整个体块的阶段，排布按受晒排，“渐变”只是离立面的深度。用户 2026-10-20 的三条澄清：
1. 功能区按 buffered → tempered → controlled 排开，**这本身就是渐变**。
2. **体块是气候基础设施，功能区连着社会行为。** controlled 按功能区定，不按整个体块勾选。
3. 平面的图景是**分层**：controlled 的久坐功能聚成一条带，靠冬季向阳的一侧；tempered 的运动功能在冷侧；buffered 的门厅在入口和边缘（用户在“分层”和“同心洋葱”之间选了分层）。

**做法：**
- **阶段指派：** 每个功能区的阶段 = 它冬季的最低阶段（“刚好够”，自动）；半室外功能 = 所在空间由围合方式推出的阶段。封闭体块一律 tempered，只提供上限（可以承载 tempered 和 controlled）；体块属性栏的“机械调节”勾选去掉。侧栏仍可手动改某个房间的阶段（“恢复自动指派”）。这取代 2026-10-17 “新区域默认 tempered、controlled 功能显示不满足”的决定。
- **渐变序列（软评判，排在受晒 / 带适配之前）：** 候选位置的周长按长度加权：贴同阶段的功能区 1；相差一级 0.7；跳级（相差两级以上，例如门厅直接贴老年中心）0.3；controlled 贴向阳外墙 1、贴背阳外墙 0.3（只散热不得热）；其他阶段贴外墙 1；还没有邻居的空边 0.5（比贴同阶段或外墙差，所以功能区会往同阶段邻居和外墙靠、聚成团）。按 10% 一档比较。**数值都是假设。**
- **向阳：** 外墙冬季总辐射在这栋楼外墙里排名 ≥ 50%（假设）；分带依据下南立面算向阳。
- **新的评判顺序：** 楼层 > （邻接）> 渐变序列 > 受晒 / 带适配 > 形状 > 紧凑。四种排布方式里“气候优先”改名“渐变优先”。
- **新指标（左栏和方案对比）：** 阶段面积占比（controlled / tempered / buffered）；controlled 成几团（同层、共墙 ≥ 1 m 连成一团）、外墙长度、其中背阳长度。目标：controlled 面积少、一团、外墙少。
- 原来按深度的“渐变适配”及其假设（阶段越高越靠内、深度只量到南北立面）已删除。

**第一次结果（65 × 42 m、顶 8.4 m、标高 0 / 4.2，受晒依据、冬季，清空记忆后）：** 一层南侧一条 controlled 带（大多功能厅、老年中心、灵活多功能室），其后更衣、行政、厨房；门厅在西南角；体育馆（tempered）在西北；二层健身中心在北侧，小的 controlled 房间沿南墙。渐变序列平均 72%，受晒适配从旧版 88% 降到 72%（预期：序列排在受晒前面），必须相邻 2/6 不变，controlled 34%、3 团（一层 1 团，二层 2 团）。

**待讨论：** 二层沿南墙的小 controlled 房间只有 2–3 m 深（面积小、长宽比 1:3 允许）；“跳级 0.3”是否对门厅—大厅的真实邻接太严；夏季阶段还没进排布。

## 9. 排布逻辑的优先级：任务书 → 建筑经验（2026-10-22，用户决定）
功能排布先满足任务书的要求（Marpole 2021 邻接、楼层、净高、直通室外，已在工具里），再用从 21 张社区中心平面归纳的建筑经验规则（`01_Research/Circulation_Patterns.md` 第 4（补）节，16 条）。流线类型（街道 / 门厅 / 环 / 更衣带）是骨架，先于房间。规则做成 skill `.claude/skills/community-centre-layout/`，还没有接进工具的评分；接进去时的次序待定（建议：硬约束 → 楼层 → 任务书邻接 → 渐变序列 → 经验规则 → 受晒 → 形状 → 紧凑，待用户确认）。

## 10. 流线骨架先于房间（2026-10-22，用户决定）
排布前先按类型（B1 穿越式门厅 / B2 门厅带 / A1 双侧街 / A2 单侧街，`Circulation_Patterns.md` 第 1 节）在最低一层画出门厅 / 街道，它是 buffered 的实体、顶替门厅功能，房间围着它放；贴骨架的边在渐变序列里按 1 计。带宽（10 / 10 / 6 / 5 m）和不穿越时的深度（50%）是假设。第 2 节“门厅紧贴入口所在的立面”在骨架模式下由骨架满足；type = none 时回到旧做法。

## 11. 两个物件：核与机房（2026-10-22）
骨架开着时：公共卫生间 + 楼梯 + 电梯 + 清洁间合成“核”（面积 = 卫生间 + 30 m²，假设），只在首层、贴骨架 ≥ 3 m（硬），最好不占外墙（软），上层同一位置自动对位；机房贴外墙 ≥ 3 m（硬），最好贴入口对面的背墙并贴体育馆（软）。软评判 objFit 排在楼层之后、其他评判之前，普通房间不受影响。依据：`Circulation_Patterns.md` 第 4（补 2）节规则 17、18、20、21、22、24。

## 12. 体块由功能决定、室外体块按邻接生成（2026-10-22）
体块面积按层反推（首层 = 首层功能 + 体育馆 + 骨架 + 核，二层 = 其余 + 核，各加 10% 余量，用户设定）；生成后收紧（二层只盖需要的部分，体育馆上空单独拉高，外圈整条空的推进来；功能变少就退回）；二层不悬挑出首层（用户决定，以后再考虑）。室外体块：广场、自行车贴入口；有顶游戏场贴灵活多功能室、有顶集市廊贴大多功能厅（依据 Marpole 任务书的直通室外要求）；围合按五阶段定义推出 exposed / protected / buffered；室外功能优先进阶段刚好够的体块。细节和数字见 `Architecture_Massing_Level_Space_Program.md`“体块方案生成第 2 版”。


## 13. 中庭：二层剩下的空产生中庭（2026-10-22，用户决定）
- 中庭是**室内、封闭、tempered**的通高空间，从首层地面通到屋顶，屋顶开天窗；不是室外。
- 大小是动态的：先排一遍功能，再在二层（及以上）剩下的空里找最大的矩形；它必须在楼里面（四周都是楼面，不贴外墙），最窄 ≥ 8 m、面积 ≥ 100 m²（两个数都是假设）；和首层门厅 / 骨架上下重叠的部分加倍计分。
- 中庭最多只拿“账面上”多出来的面积的 90%（可用室内面积 − 功能区面积合计）。原因：房间画出来比账面面积稍大，图上看着空的地方不全是真的空，不设这个上限会把后勤挤掉。
- 挖掉中庭后重排一次；功能变少或标红变多就不要这个中庭（退回）。
- 采光：贴着中庭（共墙 ≥ 3 m）的需要采光的功能，采光适配至少 0.7（同日由“只给背阳偏好、没有外墙时”改为现在这样）（天窗漫射光；0.7 是假设，工具还算不了天窗的光）。
- 渐变序列：贴中庭的边和贴门厅一样按 1 计。
- **房间靠向中庭（2026-10-22，用户决定顺序）**：先排二层 → 剩下的空定中庭 → 中庭固定 → 中庭所在楼层的房间（锁定的、核、挑空的除外）重新找位置。评分在“核与机房”之后、邻接之前加一项“贴中庭”：需要采光的功能（受晒偏好 south / north）贴中庭（共墙 ≥ 3 m）得 1；不需要外窗的功能（middle：后勤、更衣、卫生间）反过来，不贴中庭得 1，把中庭边让出来。重新排后功能变少、标红变多，或贴中庭的采光房间没有变多，就退回。这一项排在“核与机房”之后、渐变序列和受晒之前（默认的“渐变优先”方式里没有邻接这一项；“邻接优先”方式里它排在邻接之前），是我的设定，可以再调。没有中庭的楼层也按“没贴中庭”算，否则房间会为了躲开这一项搬到别的楼层（同日修正）。
- **中庭并进采光评分（2026-10-22，用户同意，取代上面“贴中庭”单独排序的做法）**：不再有单独的“贴中庭”一项。需要采光的功能（向阳、背阳偏好）贴中庭时，采光适配至少算 0.7；外墙光更好就按外墙算。所以房间只有在外墙光比中庭光差时才会去贴中庭。重排后贴中庭的采光房间没有变多就退回（不变）。

## 14. 设备与后勤不需要采光；调整后自动重排（2026-10-22，用户决定）
- **设备与后勤**采光要求最低，可以放在没有光的纯室内。排布顺序放到最后（咖啡之后），拿剩下的地方；不再必须贴外墙（取代第 11 节“机房必须贴外墙、优先背面外墙”）。评分：不占外墙最好；占了外墙最多算一半，越向阳越低；贴体育馆仍加分。
- **调整之后自动重排**（第 4 步里改了体块、标高、流线骨架或场地）：试三种排法——① 原位保留；② 大房间保位：原来放得下、现在被挤掉的功能，把压在它原位置上的没锁定房间挪开，让它回原位；③ 重新排：只留锁定的房间和核。按“放不下的室内功能少 → 标红少 → 空白少”留最好的那种。选体块方案、在第 5 步拖动房间不触发。
- 工具不会替设计师改体块（2026-10-22 用户决定：不自动改，只提示）。三种排法都放不下时，第 4 步“体块够不够用”里用红框列出：哪个功能、原来在哪个体块和楼层、为什么（按顺序检查：净高不够——写出要多少、还剩多少；流线骨架穿过它原来的位置——写出重叠尺寸和上面拉高的体块；都不是就写排布给出的原因）。使用者模式和开发者模式都显示。原先的说明：改动让体块本身放不下某个功能时（例如换入口方向后骨架穿过体育馆的高体块），三种排法都救不回来，仍显示“未放入”。

## 15. 受晒差不多时优先首层（2026-10-22，用户决定）
- 适用：没有楼层要求、不需要特别净高、不是入口和核的功能（体育馆、健身中心“最好二层”等有要求的不受影响）。
- 做法：先照常找一遍，记下这个功能在所有楼层能拿到的最好受晒（按 10% 一档）；首层位置的受晒不比它低一档以上，就优先首层。
- 排序位置：在“核与机房”之后、渐变序列之前。只排在受晒那一档里不起作用——空着的首层四周没有邻居，渐变序列分数低（实测艺术手工室：二层 0.9，首层北墙 0.5），永远比不过二层。
- 效果：背阳偏好的功能可以下到首层北墙；向阳偏好的功能只有首层也能拿到差不多的阳光时才下来，不会被拉到暗处。
- **二层再收一次（2026-10-22，用户同意）**：生成体块方案时，第一次收紧之后、加室外体块之前，按二层实际放的功能区面积 ×（1.1 / 1.25 / 1.5，依次试）再收二层：每一翼沿长边缩短（含核的那翼以核为中心，不切到核），用不上的翼去掉，再把外圈整条空的推进来；功能变少或标红变多就退回。只在生成方案时做，设计师自己的调整之后不改体块（第 14 节）。
