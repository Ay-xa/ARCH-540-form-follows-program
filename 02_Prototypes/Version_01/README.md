# Version_01：社区中心体块推演工具 v01

日期：2026-10-21 整理。状态：第一版，仍在演进。详细的建造过程见 `Assignment_2/Architecture_Massing_Level_Space_Program.md`。

## 怎么打开
用浏览器打开 `index.html` 即可（单个文件，不需要安装）。
- 第 3 步（选场地）和第 4 步起的三维视图**需要联网**：三维库从网上加载，公园和地块的轮廓向温哥华开放数据网站查询。
- 天气和风的数据已经嵌在文件里，不需要联网。

## 六个步骤
1. **选择功能**：从功能库（代码里 23 个）里勾选要放进社区中心的功能。
2. **面积与净高**：每个功能的面积和净高。
3. **选场地**：选一个公园或地块作为场地。
4. **体块推演**：编辑体块，工具划分空间并自动放置功能。
5. **确认体块与功能**：查看放置结果；点击房间，侧栏解释为什么放在这里；放不下的功能显示原因（面积不够、形状放不下、面积被分割等）。
6. **效果展示**：日照、围合阶段、季节风等的展示。

颜色表示该功能冬季所需的最低阶段（exposed → protected → buffered → tempered → controlled）。

## 主要假设和已知限制
- 很多数值是假设（面积、最大单间面积 140 m² 等），在功能库里带状态标签。
- 功能库参照 Marpole 社区中心 2021 的功能面积，只是一个项目的先例，不代表温哥华标准。
- 天气来自机场气象站，不是场地本身。
- 没有温哥华本地的舒适阈值；风界限借自多伦多；雨没有进入任何舒适计算。
- 放不下的原因共有：面积不够、没有合适的区域、面积被分割、形状放不下（2026-10-21 起单独列出）、净高不够、没有合适阶段的空间。
