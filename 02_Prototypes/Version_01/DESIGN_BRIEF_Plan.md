# 设计简报：第 5 步的平面图纸语言

日期：2026-10-20。状态：已按提案实施（同日，三个选择都按提案）；实施记录见 `Architecture_Massing_Level_Space_Program.md`“平面的图纸语言”一节。范围：只改平面（和与它共用图例的剖面、左栏色块）的画法与样式，**不碰排布逻辑**；按 `.agents/skills/frontend-design` 的流程写：先定读者和主角，再定色、字、版式、原则，再对照"一看就是生成的"默认样子做一遍自查。

## 1. 这张图是给谁看、要讲什么

- **对象：** 一张社区中心的首层 / 二层平面，画的是温哥华冬季里"气候防护的渐变"——哪些空间是 buffered、tempered、controlled，它们怎么分层。
- **读者：** 第一是你自己（推演时反复看），第二是评图的老师（看一眼就要懂）。
- **第一眼要读到：** 渐变的分层——门厅在边缘，运动类在冷侧，久坐类聚成一条暖带靠向阳的一侧。
- **第二眼要读到：** 哪里有问题——放不下的、标红的、邻接不满足的。
- **不需要在图上读到：** 评分数字、空间编号、体块编号、净高、三带比例。这些留给侧栏和左栏。

现在的平面把两眼的内容叠在一层：五个互不相干的颜色、三带色块、受晒色、邻接绿线红线、挑空斜线、锁图标、空间标签一串字。信息都在，但像调试图，不像图纸。

## 2. 主角：渐变本身

整张图只有一个出彩的地方：**阶段用一条连续的色阶表示，从冷到暖、从淡到实**。exposed 几乎是纸的颜色，controlled 是最深的一块。读图的人不用看图例也能感到"越往里越暖、越被保护"。其余一切（线、字、图例、界面）都退到灰和白。

## 3. 颜色（6 个）

| 用途 | 值 | 说明 |
|---|---|---|
| 纸 | `#FFFFFF` | 平面底色；走廊和未分配的空地就是纸，不涂 |
| 墨 | `#1F2A2E` | 外墙、文字（沿用现在的 ink） |
| 淡墨 | `#B9B3A6` | 房间分隔线、网格、次要文字 |
| 阶段色阶 | exposed `#E7EEF2` → protected `#CFDBD9` → buffered `#D9CFB0` → tempered `#D4A95A` → controlled `#8C4A2F` | 一条冷→暖、淡→实的坡；最深的两档上用白字 |
| 提示色 | `#1F4E79`（深蓝） | **只用于"有问题"和"建议"**：标红框、建议位置、不满足的邻接。暖色阶把红橙占完了，所以警示改用蓝，反而更显眼 |
| 选中 | 同提示色，实线加粗 | 不另设颜色 |

去掉：绿色"满足"连线（满足的不画，只画不满足的）；三带的黄 / 蓝色块（只在"分带依据"模式下保留，而且改成淡墨的虚线分界，不涂色）；受晒的外墙着色改成外墙外侧一道细带，默认关闭，按钮打开。

## 4. 字体

一种家族，两个角色：

- **图纸上的字：** `Bahnschrift`（Windows 自带，DIN 一路的工程字，像图纸上的注记），中文回落到 `Microsoft YaHei`。房间名 11 px，面积 9 px 淡墨，右对齐在房间右下角；不写阶段名（颜色已经说了）。
- **界面上的字：** 沿用 `Segoe UI` / `Microsoft YaHei`，但去掉 `h2` 的全大写和字距（这是生成页面最常见的记号），改为 13 px 中等字重的句首大写。
- 不加载网络字体，工具仍是一个文件。（2026-10-21 更正：原写“不联网”，但选场地和三维视图后来需要联网，见 `README.md`。）

## 5. 版式：把平面当一张图纸

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│   ┌────────────────────────────────────────┐         │
│   │  ▒▒▒▒▒▒▒▒▒▒▒▒▒▒  ░░░░░░░░░░░░░░░░░░░░ │  N      │
│   │  ▒ 体育馆      ▒  ░ 设备与后勤       ░ │  ↑      │
│   │  ▒▒▒▒▒▒▒▒▒▒▒▒▒▒  ░░░░░░░░░░░░░░░░░░░░ │         │
│   │  ▓▓▓▓▓▓▓  ████████  ████████  ████████ │         │
│   │  ▓ 门厅 ▓  █大多功能█  █老年█   █灵活█  │         │
│   └────────────────────────────────────────┘         │
│       ▲ 入口                                          │
│                                                      │
│  Level 01                    exposed ▁▂▃▅▇ controlled │
│  冬季 · 外墙受晒              ▢ 未放入 3   ▢ 需要调整 2 │
└──────────────────────────────────────────────────────┘
```

- **图框：** 平面左对齐放在一张"纸"里，纸有一圈留白；指北针只是一个 N 和短线，放右上角。
- **外墙：** 墨色 2 px；房间之间 0.75 px 淡墨；体块虚线轮廓只在有两个以上体块时画。
- **挑空：** 不画斜线，改成房间色阶上叠一层 8% 的白，并在面积后写"挑空"两个字。
- **锁定：** 房间左上角一个 8 px 的小方块（墨色），不用 🔒 表情。
- **标题块（纸的下沿）：** 左边大字"Level 01"，下一行小字写季节和依据；右边是色阶条，五个刻度下各写阶段名；最右两个小计数"未放入 / 需要调整"，点了跳到左栏。标题块取代现在平面上方那串 "L01-S1 · tempered · 2,730 m² · 净高 3.8 m · 体块 M1"。
- **邻接：** 默认不画线。点一个房间，只画它自己不满足的那几条（深蓝虚线）；"显示全部不满足"做成开关。
- **剖面** 用同一条色阶、同样的线宽和字。

## 6. 原则

1. 图是主角，界面是边框：面板全部退成白和灰，只有图上有颜色。
2. 一条色阶讲阶段，一种蓝讲问题；再没有第三种颜色系统。
3. 线型编码信息：实线是真墙，虚线是建议或问题，不用线型做装饰。
4. 字只写读者下一步要用的：名字和面积；别的进侧栏。
5. 没有动效（第 6 步的晕染保留，那是另一种用途）。

## 7. 对照"默认样子"的自查

- 米色底 + 衬线大标题 + 陶土色强调：没有。底是白纸，字是无衬线，暖色在图里是数据不是装饰。
- 全大写小标签、中间点串起来的元信息（"A · B · C"）：现在的界面两样都有，这次去掉；标题块里用换行，不用中间点。
- 一样圆角的卡片阵列：左栏的卡片保留但去掉阴影，圆角统一 3 px，只在"需要调整"的卡片上用深蓝左边线区分。
- 工程字做小标签：Bahnschrift 用在图纸注记上是有原因的（图纸传统），不用在界面正文。
- 暖色阶最深一档 `#8C4A2F` 刻意避开 `#D97757` 一类的陶土色。

## 8. 不改什么、怎么验证

- 不改：`scoreRect`、`generateLayout`、空间识别、三维、第 3 步地图、第 6 步场景。颜色变量 `--exposed … --controlled` 的名字不变，只换值，所以三维和左栏自动跟上。
- 验证：① 同一组输入改前改后的房间位置、未生成原因逐项一致（5 组回归）；② 每一档色阶上的文字对比度至少 4.5:1（最深两档换白字）；③ 截图并排放在 `04_Presentation/screenshots/`，改前改后各一张；④ 控制台无报错。

## 9. 需要你定的三件事

1. 色阶走向：冷淡 → 暖实（上面的提案），还是全部同一色相只变深浅？
2. 警示色用深蓝可以吗？（代价：红色不再表示"问题"）
3. 图纸注记字体用 Bahnschrift（Windows 自带；在 Mac 上会回落到系统字），还是干脆全用 YaHei？
